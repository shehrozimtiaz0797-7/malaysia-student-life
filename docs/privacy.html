Privacy policy

Last updated: 22 November 2026

"Malaysia Student Life Uploader" is a private tool used only by the owner of the YouTube channel Malaysia Student Life to upload that channel's own videos.

What data the app uses

With the owner's permission (Google OAuth), the app uses the YouTube Data API to upload videos, set titles, descriptions and thumbnails, and read basic statistics of the owner's own channel.

What we do not do

The app does not collect data from other people, does not sell or share any data, and does not use Google user data for advertising. Access tokens are stored only as encrypted secrets of the owner's own automation.

Google API Services

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the Google Privacy Policy.

Removing access

The owner can remove the app's access at any time at myaccount.google.com/permissions.
